# Créditos dos sprites

Personagens derivados de **Free Wraith Tiny Style 2D Sprites**, da CraftPix
(<https://craftpix.net>), licença free da CraftPix
(<https://craftpix.net/file-licenses/>).

Os arquivos aqui são strips gerados por `scripts/craftpix-sheets.py` a partir das
sequências PNG do pacote. O pacote bruto **não** é versionado (a licença free
proíbe redistribuir os arquivos originais): baixe em craftpix.net e extraia em
`assets/craftpix/` antes de rodar o script.

```bash
python scripts/craftpix-sheets.py --height 64
```
